# Privacy and interpretation

Relationship OS runs entirely in the browser. It has no analytics, external fonts, remote libraries, backend, synchronization or LLM calls. Loading the hosted site contacts GitHub Pages for the app itself; questionnaire answers are not transmitted by the app.

Answers and imported partner results are saved in localStorage for the current browser origin. This is not encrypted storage and profiles on a shared browser are not access-controlled. Other people using that browser can open them. Clearing browser data can erase them. Download JSON for a local backup.

Downloads and clipboard copies happen only when selected. Copying for ChatGPT does not open or send to ChatGPT; review the contents and decide what to paste yourself. The combined export contains both participants' answers, historical notes, memory confidence and mirror answers. Share only material each participant has agreed to share. Exported files are ordinary local files: their folder's sync and backup settings apply.

Import currently adds a partner's result for comparison; it does not restore an editable personal profile. A downloaded HTML and the Pages URL have different storage origins. Fill in the questionnaire at the URL you intend to keep using.

Starting over clears the active profile's answers and its imported partner result, after confirmation. Other profiles and previously downloaded files remain.

The same questions apply to both participants. Each may give, receive, need, act and interpret. Numeric differences are descriptive, not compatibility or diagnostic scores. Retrospective ratings are memories, not causal measurements. Free text is displayed side by side; semantic interpretation is left to an explicitly requested ChatGPT conversation.

Never commit personal responses, context/perspective documents, medical records, private photos or the handoff archive to this public repository. Tests contain synthetic example responses only.
